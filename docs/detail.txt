* what is the meaning of models,routes,controller.middleware?

- model :
    Defines how the data looks and how it’s stored in the database.
    Think of it like a blueprint for your MongoDB collection.
    Collection name will be users.
    Each document will follow this structure.

- controller :
    Contains functions that do the real work (business logic).
    Controllers use the model to talk to MongoDB.

- routes :
    Connects URLs (API endpoints) to controller functions.
    /register → send request to userCtrl.registerUser
    /login → send request to userCtrl.loginUser

- server :
    Ties everything together.


- data flow :
    React (frontend form) 
    ↓ POST request
    Express Route (userRoutes.js)
        ↓ calls
    Controller (userCtrl.js)
        ↓ uses
    Model (User.js → MongoDB collection "users")
        ↓ save data
    MongoDB (HealthyTrack database)
        ↓
    Response → Controller → Route → Back to React

- Summary

    Model → database structure

    Controller → logic (register, login, verify)

    Routes → API endpoints

    Server.js → glue for everything

    Data flow → React → Route → Controller → Model → MongoDB → back to React
